# Command-Line Rust by Ken Youens-Clark

This repository contains all the solved code from the Command-Line Rust book.
I picked up this book to have a gentler slope in working with the Rust programming 
language owing to the fact that my previous attempts at learning the language 
have not lead to sufficient proficiency where I could think in Rust.

I am not very handy with the syntax so my hope has been that after completing 
this book, I can think and program like a Rustacean.
